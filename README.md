## 🚀 Featured Projects

### 🧠 [CYRA — AI Resume Platform](https://github.com/Antwa-sensei253/Cyra)
> React · Django REST · PostgreSQL · Groq · Gemini API

A live freelance platform on **Nafezly** that matches users with jobs via AI-driven resume analysis. Features keyword-matrix extraction, ATS compliance scoring, and a dual-LLM fallback pipeline (Gemini → Groq DistilBERT) ensuring 99% uptime. Deployed on Vercel + Render with OAuth2/JWT auth.

---

### 🏙️ [UrbanFix — Civic Maintenance Platform](https://github.com/Antwa-sensei253/UrbanFix)
> ASP.NET Core · React · Entity Framework · SQL Server · JWT

Built at a government hackathon under the **Governor's Executive Office**. Connects citizens, technicians, and officials through 4 role-based workflows with geolocated issue tracking, SLA escalation workers, and governance analytics dashboards.

---

### 💬 [Django Discuss — Forum App](https://github.com/Antwa-sensei253/Django-Discuss)
> Django · Python · PostgreSQL

Full-featured discussion forum with threaded comments, complete auth (register/login/reset), and a normalized PostgreSQL schema supporting concurrent users.
